# Python Data Cleaning and Visualization Projects

This repository contains two real-world Python projects focused on **data cleaning**, **exploratory data analysis (EDA)**, and **visualization**. These projects simulate practical challenges such as missing values, inconsistent formats, junk entries, and outliers — all solved using `Pandas`, `Matplotlib`, and `Seaborn`.

---

## 🔍 Projects Overview

### 📁 Project 1: HR Analytics – Data Cleaning & Visualization

**Objective:**  
Prepare a clean and visualized HR dataset suitable for reliable analytics and reporting.

**Dataset Issues Addressed:**
- Missing or placeholder values (`NaN`, `unknown`)
- Invalid or unrealistic values (e.g., negative salary, incorrect age)
- Corrupt dates
- Duplicates
- Inconsistent department naming

**Visualizations Included:**
- Age Distribution Histogram
- Salary Boxplot (with outliers treated)
- Department Count Bar Chart
- Annual Hiring Trend

**Tools Used:**  
`Pandas`, `NumPy`, `Matplotlib`, `Seaborn`

---

### 📁 Project 2: Healthcare Analytics – Patient Data Preparation

**Objective:**  
Clean and structure patient data to support demographic profiling, diagnosis tracking, and departmental load analysis.

**Dataset Issues Addressed:**
- Inconsistent gender labels (e.g., `M`, `Male`, `unknown`)
- Invalid or missing ages
- Dirty date fields (`VisitDate`)
- Mixed-format blood pressure readings (e.g., `'120/80'`)
- Placeholder values in diagnosis and notes
- Duplicate records

**Visualizations Included:**
- Age Distribution of Patients
- Gender Distribution Bar Chart
- Department Visit Counts
- Blood Pressure Boxplots (Systolic & Diastolic)
- Monthly Patient Visit Trend

**Tools Used:**  
`Pandas`, `NumPy`, `Matplotlib`, `Seaborn`

---

## 📊 Skills Demonstrated

- Real-world data cleaning (missing, invalid, junk values)
- Categorical normalization (gender, diagnosis)
- Date/time parsing and trend analysis
- Outlier treatment using IQR
- Custom visual storytelling through EDA
